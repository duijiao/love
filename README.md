# 冬日弹窗

纯静态页面 + Supabase，可直接放 GitHub Pages。

## 部署
1. **Supabase**：新建项目 → SQL Editor 依次运行 `schema-1.sql`（模板和分享）、`schema-2.sql`（图片和语音的存储桶）、`schema-3.sql`（可选：放宽到 6MB，上传背景音乐需要）。
2. 把 Project URL 和 anon key 填进 `config.js`（不要用 service_role key）。
3. **GitHub**：新建仓库，上传全部文件 → Settings → Pages → 选 main 分支根目录。
   `config.js.bak` 不需要上传。

## 链接格式
- `…/?s=xxxxxxxx`：分享链接，内容存在 Supabase，直接进入模板，没有任何按钮
- `…/?t=love&to=小明&from=小红`：直接打开某个模板（可选 `&env=0` 跳过信封）
- 不带参数：创作页（修改 / 更多 / 分享 / 音乐 / 重播）

## 图片和语音窗口
- 修改 → 「图片和语音窗口」：添加图片、直接录一段语音（最长 30 秒）、或上传 mp3 / m4a / wav / ogg（2.5MB 以内），最多 8 个。
- 每个附件可以配一句话，并选择在第几条文字之后弹出。
- 语音窗口有播放键和波形进度，播放时背景音乐自动压低；可选「弹出时自动播放」。信封开场时点开信封就能自动播放，不开信封时浏览器可能拦截，播放键会闪一下提示。
- 图片点一下看大图。图片会压到最长边 1024px 的 JPEG，同时去掉拍摄位置等信息。
- 没分享之前，文件只存在你自己浏览器的 IndexedDB 里；点「分享」时才上传到 Supabase Storage 的 `media` 桶，分享数据里只存公开地址。
- 分享页只认自己 Storage 里的地址，别人伪造的链接不能引用外站图片。

## 拍立得 / 胶片照片墙
- 修改 → 「图片样式」：普通窗口 / 拍立得（白边 + 手写字）/ 胶片（底片边框）/ 两种交替。
- 每张照片带一点随机倾斜，没有标题栏，按住照片任意位置拖动，点一下看大图，右上角 × 关闭；照片配的那句话会手写在白边或底片上。

## 自带背景音乐
- 修改 → 「背景音乐」：上传一首 mp3 / m4a / wav / ogg（6MB 以内），替换内置的八音盒；可以试听，也可以改回内置。
- 会循环播放；语音窗口播放时自动压低（iOS 上改为暂停再继续）。放自己的歌时不再叠加“叮”声。
- 分享页：有歌时右下角只留一个音乐开关，第一次点屏幕就开始播放；开了信封则点开信封时开始。
- 歌曲和图片一样，点「分享」时才上传到 `media` 桶。请只用你有权使用的音乐。

## 拼图告白
- 修改 → 勾选「拼图告白」（需要同时开着压轴窗口）：压轴那句话会拆成 2~5 块碎片，按顺序咬合（右边凸起、左边凹进）。
- 有照片时，碎片藏在照片窗口后面，只露出一条缝；把照片拖开才能拿到。照片不够的话，其余碎片在最后散落出现。
- 把碎片按顺序拖到一起会自动吸附；拼完整后碎片发光、爆出爱心，变成压轴窗口（表白模板带「愿意 / 再想想」）。
- 句子太长、手机屏幕放不下时会自动退回普通压轴窗口。

## 已搬到服务器的内容
- 模板（配色、文案、飘落特效、信封/爱心/压轴设置）：`templates` 表，在 Table Editor 改行即生效
- 分享内容：`shares` 表，只能新增，只能按 id 读取
- 图片和语音：`media` 桶，只能新增，不能列出、修改、删除；知道完整链接的人可以打开
- 未配置 Supabase 或网络失败时，自动使用内置模板，分享退回长链接（此时图片和语音放不进链接）
