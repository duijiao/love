# 冬日弹窗

纯静态页面 + Supabase，可直接放 GitHub Pages。

## 部署
1. **Supabase**：新建项目 → SQL Editor 依次运行 `schema-1.sql`（模板和分享）、`schema-2.sql`（图片和语音的存储桶）、`schema-3.sql`（可选：放宽到 6MB，上传背景音乐需要）。
2. 把 Project URL 和 anon key 填进 `config.js`（不要用 service_role key）。
3. **GitHub**：新建仓库，上传全部文件 → Settings → Pages → 选 main 分支根目录。
   `config.js.bak` 不需要上传。

## 链接格式
- `…/?s=xxxxxxxx`：分享链接，内容存在 Supabase，直接进入模板，没有任何按钮
- `…/?t=love&to=小明&from=小红`：直接打开某个模板（可选 `&env=0` 跳过信封）
- 不带参数：创作页（修改 / 更多 / 分享 / 音乐 / 重播）

## 图片和语音窗口
- 修改 → 「图片和语音窗口」：添加图片、直接录一段语音（最长 30 秒）、或上传 mp3 / m4a / wav / ogg（2.5MB 以内），最多 8 个。
- 每个附件可以配一句话，并选择在第几条文字之后弹出。
- 语音窗口有播放键和波形进度，播放时背景音乐自动压低；可选「弹出时自动播放」。信封开场时点开信封就能自动播放，不开信封时浏览器可能拦截，播放键会闪一下提示。
- 图片点一下看大图。图片会压到最长边 1024px 的 JPEG，同时去掉拍摄位置等信息。
- 没分享之前，文件只存在你自己浏览器的 IndexedDB 里；点「分享」时才上传到 Supabase Storage 的 `media` 桶，分享数据里只存公开地址。
- 分享页只认自己 Storage 里的地址，别人伪造的链接不能引用外站图片。

## 拍立得 / 胶片照片墙
- 修改 → 「图片样式」：普通窗口 / 拍立得（白边 + 手写字）/ 胶片（底片边框）/ 两种交替。
- 每张照片带一点随机倾斜，没有标题栏，按住照片任意位置拖动，点一下看大图，右上角 × 关闭；照片配的那句话会手写在白边或底片上。

## 自带背景音乐
- 修改 → 「背景音乐」：上传一首 mp3 / m4a / wav / ogg（6MB 以内），替换内置的八音盒；可以试听，也可以改回内置。
- 会循环播放；语音窗口播放时自动压低（iOS 上改为暂停再继续）。放自己的歌时不再叠加“叮”声。
- 分享页：有歌时右下角只留一个音乐开关，第一次点屏幕就开始播放；开了信封则点开信封时开始。
- 歌曲和图片一样，点「分享」时才上传到 `media` 桶。请只用你有权使用的音乐。

## 拼图告白
- 修改 → 勾选「拼图告白」（需要同时开着压轴窗口）：压轴那句话会拆成 2~5 块碎片，按顺序咬合（右边凸起、左边凹进）。
- 有照片时，碎片藏在照片窗口后面，只露出一条缝；把照片拖开才能拿到。照片不够的话，其余碎片在最后散落出现。
- 把碎片按顺序拖到一起会自动吸附；拼完整后碎片发光、爆出爱心，变成压轴窗口（表白模板带「愿意 / 再想想」）。
- 句子太长、手机屏幕放不下时会自动退回普通压轴窗口。

## 小猫送信
- 修改 → 勾选「小猫送信」：每个窗口先藏起来，由一只像素小猫从屏幕两侧叼着信跑来，放下后窗口才弹出，小猫再跑出屏幕。压轴窗口由小猫送来一个礼物盒，盒子抖几下后打开。
- 系统开了「减少动态效果」时自动关闭。

## 小猫打翻东西
- 修改 → 勾选「小猫打翻东西」（需开着「小猫」，开启后替代「叼信送来」）：屏幕上方落下一张桌子，小猫从屏幕外一跃跳上桌子。每个窗口先弹到桌上，小猫走过去用爪子推；窗口越大越“重”，重的要先使劲推一下（“嘿咻…”）才推得动。
- 窗口从桌边翻落，边落边放大（像朝你砸过来），落地时压扁、弹两下、晃一晃，伴随一声低沉的“咚”；越大越沉，屏幕震得越狠，扬起灰尘，地上有随高度变化的影子。窗口最终落在原本排好的位置（散落 / 爱心）上。
- 桌上先摆着一只杯子和一盆小植物：小猫会先把它们一个个拍下去，摔成像素碎片，然后才开始推窗口。
- 连锁反应：窗口砸地时，已经落地的邻居会被震得跳一下、歪一歪；特别大的窗口（照片）如果砸在别的窗口上，会把下面那个砸出一道裂纹（只在窗口一角，不挡文字），伴随“咔”的一声。
- 全部推完后小猫心满意足地跳下桌子，桌子收走，才会进入逗猫棒 / 猜纸箱 / 压轴礼物盒；拼图碎片、署名也等推完再出现。
- 压轴窗口仍由小猫叼着礼物盒送来；系统开了「减少动态效果」时自动关闭。

## 叼回来（再想想）
- 开着「小猫打翻东西」时，对方在压轴窗口连点 3 次「再想想」，桌子会再落下来，小猫跳上桌，把摔在地上的窗口一个个叼回桌上，重新推下去，最多 5 遍；压轴窗口始终在最上面，「愿意」随时点得到。
- 点「愿意」：小猫立刻停手，桌子收走，窗口原地放好，接着放烟花。

## 小猫举牌签名
- 填了落款（收件人 / 落款）并开着「小猫」时，看完之后小猫举着写了「给 ××／—— 落款」的小牌子，从屏幕一侧走到中间坐好，牌子轻轻摇晃，还会开心地喵一声。
- 触发时机：表白（带「愿意」）在点「愿意」、烟花结束后；其他模板在压轴窗口出现 / 所有窗口出完之后。

## 拍立得合影
- 修改 → 勾选「拍立得合影」（需开着「小猫」和压轴窗口，只在带「愿意 / 再想想」的模板里出现）：点「愿意」后，一个拍立得相框从上面掉下来，小猫跑进相框里，倒数 3、2、1，咔嚓一声闪光，照片慢慢“显影”，白边上手写「你们的小猫合影」，下面一行小字是落款、小猫名字和日期。
- 照片是按你们的小猫（毛色、花纹、眼睛、领结）和当前主题配色实时画出来的，点「保存图片」存成 PNG：手机弹出系统分享面板（可存到相册），电脑直接下载。微信等内置浏览器不一定能下载，可以长按照片保存。
- 有「跳过」；拍完点「继续」进入下一步。

## 爱心蛋糕
- 修改 → 勾选「爱心蛋糕」（同样需要小猫和压轴窗口）：合影之后、放烟花之前，小猫走到桌边，用爪子把一个蛋糕推下桌，蛋糕落地压扁、弹两下、扬起灰尘，随后三根蜡烛依次亮起。
- 吹一口气（麦克风）或点一下屏幕，蜡烛熄灭，才开始放烟花。麦克风只在蜡烛亮起后才请求，只用来听音量，不录音、不上传；不允许或设备没有麦克风时，自动改成点一下。吹气时火苗会跟着歪。右下角有「直接放烟花」。
- 麦克风需要 https（GitHub Pages 默认就是）。

## 压轴烟花
- 修改 → 勾选「压轴烟花」：点「愿意」后，所有窗口炸成烟花，夜空里再放几发礼花，最后粒子聚成压轴那句话和一颗心，停几秒后渐隐。点屏幕可以跳过。
- 只在带「愿意 / 再想想」按钮的模板（表白）里触发。开着「拍立得合影」/「爱心蛋糕」时，顺序是：点「愿意」→ 合影 → 推蛋糕、吹蜡烛 → 烟花。

## 你们的小猫
- 修改 → 「你们的小猫」：起名字、选毛色（奶油/橘/灰/黑/白）、花纹（花斑/虎纹/白袜子）、眼睛颜色、领结，有实时预览。信封上会写「××叼来的信」，窗口标题栏变成「××· 第 N 封」。
- 屏幕左下角常驻一只小猫：一阵子没人碰就趴下睡着（冒 z z z），一碰就惊醒；点它会炸毛喵一声；对方点两次以上「再想想」它会背过身生气，点「愿意」后高兴得尾巴转成螺旋桨。
- 压轴烟花时，小猫蹲在屏幕下方仰着头看，眼睛映着烟花的颜色；第一发礼花炸响时被吓得跳起来，回头看你一眼，聚成字时眯眼笑。
- 这些都跟着「小猫」那个勾选开关走；系统开了「减少动态效果」时动画会自动关闭。

## 逗猫棒小游戏
- 修改 → 勾选「逗猫棒小游戏」（需开着「小猫」）：所有窗口出完后，屏幕变暗，手指（或鼠标）变成一根逗猫棒，小猫追着它跑。逗到小猫 4 次，小猫才叼着礼物盒送来压轴窗口。
- 小猫越逗越兴奋、跑得越快；25 秒没完成它会玩累，直接继续；右下角有「跳过」。
- 不会影响拼图告白（拼图完成后直接出压轴窗口）。

## 猜纸箱小游戏
- 修改 → 勾选「猜纸箱小游戏」（需开着「小猫」）：压轴前出现三个纸箱，小猫跳进其中一个，纸箱来回换位 6 次，猜对了小猫探出头，才叼着礼物盒送来压轴窗口；猜错的纸箱里只有搞笑的话。
- 和逗猫棒可以同时开：先逗猫棒，再猜纸箱，最后送礼物盒。都有「跳过」。

## 小猫配音
- 修改 → 勾选「小猫配音」：用真猫的叫声（`meows.js`，由上传的录音裁成 7 声，已去静音、统一响度），没有这个文件时不发声。送信时每个窗口的“喵”音高不同（五声音阶），睡醒是上扬的“喵？”，点它是短促的“喵!”，生气是低低的“哼”，高兴是连着两声，睡着时有轻轻的呼噜。烟花里小猫被吓到时也会叫。
- 和音乐开关联动：右下角「音乐」关着就不会出声。放自己上传的歌时，配音照常。

## 已搬到服务器的内容
- 模板（配色、文案、飘落特效、信封/爱心/压轴设置）：`templates` 表，在 Table Editor 改行即生效
- 分享内容：`shares` 表，只能新增，只能按 id 读取
- 图片和语音：`media` 桶，只能新增，不能列出、修改、删除；知道完整链接的人可以打开
- 未配置 Supabase 或网络失败时，自动使用内置模板，分享退回长链接（此时图片和语音放不进链接）
